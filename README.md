# 🎓 AcademicAI Advisor

Platform konsultan akademik berbasis AI yang membantu mahasiswa dalam perencanaan studi, pemilihan mata kuliah, dan arahan skripsi berdasarkan profil dan IPK mereka.

## 🛠️ Tech Stack
- **Frontend:** Next.js (App Router), React, Tailwind CSS
- **Backend:** Express.js, Node.js
- **Database:** PostgreSQL (via Prisma ORM)
- **AI Integration:** OpenAI API

## 🚀 Quick Start
1. Clone repository ini.
2. Setup Backend: `cd backend && npm install && npx prisma migrate dev`
3. Setup Frontend: `cd frontend && npm install`
4. Jalankan kedua server dan buka `http://localhost:3000`.
